## 🚀 Quick Start

### 1. Environment Setup
Clone the repository and install the modernized dependency tree:
```bash
git clone https://github.com/realkeshav08/Code-with-Ai.git
cd CodePulse

npm install --legacy-peer-deps
```

### 2. Configuration
Create a `.env` file and authenticate with your Gemini API Key:
```env
VITE_GOOGLE_API_KEY=your_gemini_api_key_here
```

### 3. Launch
Fire up the development environment:
```bash
npm run dev
```
